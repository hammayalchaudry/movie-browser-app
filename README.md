# movie-browser-app
# 🎬 CineVault - Movie Browser App  A modern React &amp; Node.js app powered by OMDb API.  ### Features - 🌐 **Global State:** React Context API (No prop-drilling) **Skeleton Loaders:** Shimmer effects during fetch  **Empty States:** Custom UI for 0 search results &amp; empty watchlist  **Modal Specs:** IMDb ratings, plots &amp; cast  Watchlist &amp; Toast Alerts
